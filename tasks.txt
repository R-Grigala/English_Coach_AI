# English Coach AI — სამუშაოების სია

სტატუსები: [x] შესრულებულია · [~] ნაწილობრივ შესრულებულია / შესამოწმებელია · [ ] გასაკეთებელია · [—] გამორიცხულია გადაწყვეტილებით

## პროდუქტის შეთანხმებული ფარგლები

- პლატფორმა პირადი და ერთმომხმარებლიანია.
- რეგისტრაცია, login, users/user ownership და JWT ამ ვერსიისთვის საჭირო არ არის. PDF-ში მოცემული Auth ამოცანები განზრახ გამორიცხულია.
- სამიზნე: ინგლისურის გაუმჯობესება A2-დან B2-მდე ყოველდღიური, პროფესიული და აკადემიური პრაქტიკით.
- შენიშვნა API key-ზე: PDF ითვალისწინებს key-ის backend environment-ში შენახვას. საიტიდან key-ის შეყვანის მოთხოვნისთვის დაემატა backend-ზე დაშიფრული ლოკალური შენახვა (`backend/instance/`); production-მდე ეს განსხვავება უნდა გადაიხედოს.

## Phase 2 — Core Backend

- [x] მონაცემთა ბაზის მოდელები — ერთმომხმარებლიანი პროფილი, გეგმები/გაკვეთილები/სექციები, საერთო ლექსიკონი და კატეგორიები, პირადი სიტყვების პროგრესი და review-ები, გრამატიკა/სავარჯიშოები/შედეგები, საუბრები და პროგრესის ისტორია.
- [x] Flask-Migrate-ის საწყისი migration და Alembic scaffold; PostgreSQL-ზე მიმდინარე და head ვერსიები ემთხვევა (`0001_core_learning`).
